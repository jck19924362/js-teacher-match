# 江苏教师招聘 · 智能匹配

**在线使用**：<https://jck19924362.github.io/js-teacher-match/>

3 分钟填好个人档案，立刻看清你能报哪些江苏教师编制岗位。

## 它能做什么

- 📋 填一次档案（学历 / 院校 / 专业 / 教资 / 荣誉 / 户籍），自动逐条比对 136 个在库岗位的报名条件
- ✅ 每个岗位给出结论：**可报 / 待确认 / 不符**，并写明原因和风险提示
- 📅 收藏岗位自动生成**报考时间线**，按截止日期排列
- 🎯 支持幼儿园 / 小学 / 初中 / 高中四个学段分别查看

## 数据说明

- 覆盖江苏 13 个地市，数据整理自各地教育局/人社局**公开招聘公告原文**
- 每条岗位标注来源置信度（官网原文 / 第三方转载），并提供原公告链接供核实
- 当前在库以 2026 届公告为主，2027 届提前批公告发布后将持续更新
- 仅供参考，报名前请务必以公告原文为准

## 技术实现

纯前端三件套（HTML + JS + JSON 数据），无后端、无构建、无依赖，GitHub Pages 直接托管，所有计算在浏览器本地完成。
